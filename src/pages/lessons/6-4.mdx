<Callout type="tip" title="المربع معين ومستطيل">

كل مربع معين (أضلاعه متساوية)، وكل مربع مستطيل (زواياه قائمة). لكن ليس كل معين مربعًا، وليس كل مستطيل مربعًا. فكّر في الأمر كدوائر متداخلة: المعينات دائرة، والمستطيلات دائرة، والمربعات هي المنطقة المشتركة بينهما.

## قطرا المعين والمستطيل

<Term id="thm-rhombus-diagonals" />
<Term id="thm-rect-diagonals" />

جرّب في المختبر أعلاه: اضغط «معين» ثم «مستطيل» ثم «مربع»، وراقب قائمة الخصائص تتغير.

| الخاصية | متوازي الأضلاع | المستطيل | المعين | المربع |
|---|:-:|:-:|:-:|:-:|
| القطران ينصف كل منهما الآخر | ✓ | ✓ | ✓ | ✓ |
| القطران متطابقان | | ✓ | | ✓ |
| القطران متعامدان | | | ✓ | ✓ |
| كل قطر ينصف زاويتين | | | ✓ | ✓ |

<Example title="مثال 1: قطرا المستطيل">

في المستطيل $ABCD$، القطران يتقاطعان في $E$، و $AE = 6.5$. أوجد $BD$.

1. القطران ينصف كل منهما الآخر: $AC = 2 \cdot AE = 13$.
2. قطرا المستطيل متطابقان: $BD = AC = 13$.

</Example>

<Example title="مثال 2: زوايا المعين">

في المعين $PQRS$، $m\angle QPR = 35^\circ$. أوجد $m\angle QPS$ و $m\angle PQR$ والزاوية بين القطرين.

1. القطر $\overline{PR}$ ينصف $\angle QPS$: $m\angle QPS = 2 \times 35 = 70^\circ$.
2. $\angle PQR$ متتالية مع $\angle QPS$: $m\angle PQR = 180 - 70 = 110^\circ$.
3. قطرا المعين متعامدان: الزاوية بينهما $90^\circ$.

</Example>

<Example title="مثال 3: هل هو معين؟">

متوازي أضلاع قطراه طولاهما $10$ و $10$. هل هو معين أم مستطيل أم مربع؟

1. القطران **متطابقان**، فهو مستطيل.
2. لا نعرف هل القطران متعامدان، فلا نستطيع القول إنه معين.
3. إذن: مستطيل بالتأكيد، وقد يكون مربعًا، ولا نستطيع الجزم بأكثر من ذلك.

</Example>

## الخلاصة

- **المعين** أضلاعه متطابقة؛ قطراه متعامدان، وكل قطر ينصف زاويتين.
- **المستطيل** زواياه قائمة؛ قطراه متطابقان.
- **المربع** معين ومستطيل، فله الخصائص كلها.
- الثلاثة متوازيات أضلاع، فترث خصائص الدرس 6.2 كلها.
