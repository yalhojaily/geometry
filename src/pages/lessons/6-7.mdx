<Callout type="warning" title="الارتفاع عمودي دائمًا">

أكثر خطأ شائع: ضرب القاعدة في طول الضلع المائل. الارتفاع $h$ هو **البعد العمودي** بين القاعدتين، أو بين القاعدة والرأس المقابل، ويُرسم عادة خطًا متقطعًا بعلامة زاوية قائمة.

</Callout>

<Example title="مثال 1: متوازي الأضلاع">

متوازي أضلاع قاعدته $12$، وضلعه المائل $5$، وارتفاعه $4$. أوجد مساحته ومحيطه.

1. المساحة: $A = bh = 12 \times 4 = 48$.
2. المحيط يستخدم الأضلاع لا الارتفاع: $P = 2(12 + 5) = 34$.

</Example>

<Example title="مثال 2: شبه المنحرف">

قاعدتا شبه منحرف $9$ و $15$، وارتفاعه $6$. أوجد مساحته.

1. $A = \tfrac{1}{2}h(b_1 + b_2) = \tfrac{1}{2}(6)(9 + 15)$.
2. $= 3 \times 24 = 72$.
3. لاحظ: $\tfrac{1}{2}(b_1 + b_2)$ هو طول القطعة المتوسطة (الدرس 6.5). فالمساحة = القطعة المتوسطة × الارتفاع.

</Example>

<Example title="مثال 3: المعين">

قطرا معين $10$ و $24$. أوجد مساحته وطول ضلعه.

1. $A = \tfrac{1}{2}d_1 d_2 = \tfrac{1}{2}(10)(24) = 120$.
2. القطران متعامدان وينصف كل منهما الآخر، فكل ضلع وتر لمثلث قائم ساقاه $5$ و $12$.
3. بنظرية فيثاغورس (الفصل 9): الضلع $\sqrt{25 + 144} = 13$.

</Example>

<Example title="مثال 4: ارتفاع مجهول">

مثلث مساحته $42$ وقاعدته $12$. أوجد ارتفاعه.

1. $42 = \tfrac{1}{2}(12)h = 6h$.
2. $h = 7$.

</Example>

## الخلاصة

| الشكل | المساحة |
|---|---|
| المستطيل | $A = bh$ |
| متوازي الأضلاع | $A = bh$ (الارتفاع عمودي) |
| المثلث | $A = \tfrac{1}{2}bh$ |
| شبه المنحرف | $A = \tfrac{1}{2}h(b_1 + b_2)$ |
| الطائرة الورقية والمعين | $A = \tfrac{1}{2}d_1 d_2$ |

- كل الصيغ تُشتق من مساحة المستطيل بالقص وإعادة الترتيب.
